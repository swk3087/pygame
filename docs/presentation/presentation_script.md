# Gravity Rotate 슬라이드용 정리

10장 이내 PPT에 바로 넣기 위한 슬라이드 텍스트 초안입니다.

---

## 슬라이드 1. 제목

- Gravity Rotate
- 원버튼 중력 회전 퍼즐 게임
- 이미지: `docs/presentation/gravity_rotate_ingame.png`

---

## 슬라이드 2. 게임 소개

- 장르: 퍼즐 액션 게임
- 조작: 클릭 또는 터치 1회
- 목표: 중력을 바꿔 목표 타일까지 도달
- 특징: 이동보다 타이밍 판단이 중요한 구조

---

## 슬라이드 3. 기획 의도

- 조작은 단순하게, 플레이는 전략적으로 설계
- 한 번의 입력이 전체 이동 경로를 바꾸는 구조
- 짧은 레벨에서도 퍼즐성과 긴장감을 느끼도록 기획
- 초반은 직관적, 후반은 사고력 중심 난이도 구성

---

## 슬라이드 4. 핵심 메커닉

- 입력 시 중력이 90도 반시계 방향으로 회전
- 속도 벡터도 함께 회전해 관성 유지
- 벽을 이용해 이동 경로 제어
- 가시, 포탈, 목표 타일로 퍼즐 구조 강화

---

## 슬라이드 5. 기술 스택

- Python 3
- Pygame 2
- JSON 기반 맵 데이터
- `save.json` 기반 저장 시스템
- 외부 의존성을 최소화한 구조

---

## 슬라이드 6. 프로젝트 구조

- `core`: 실행, 설정, 저장, 씬 전환
- `scenes`: 메인 메뉴, 레벨 선택, 설정, 게임, 결과 화면
- `gameplay`: 플레이어, 포탈, 타일맵, 파티클
- `map`: JSON 레벨 파일

---

## 슬라이드 7. 구현 설명

- 타일 기반 충돌 처리
- X축, Y축 분리 충돌 해결
- 포탈 그룹 텔레포트와 재진입 쿨다운 구현
- 맵 폴더 자동 스캔으로 레벨 자동 반영
- HUD, 일시정지, 결과 화면까지 포함한 플레이 흐름 구성

---

## 슬라이드 8. 완성도 요소

- 메인 메뉴, 설정, 레벨 선택 화면 구현
- 레벨 해금 및 설정 저장 기능
- 파티클, 화면 연출, 개선된 타일 비주얼 적용
- 튜토리얼부터 고난도까지 단계별 레벨 구성

---

## 슬라이드 9. 기대 효과 및 확장성

- 단순한 조작만으로도 깊이 있는 퍼즐 플레이 제공
- JSON 기반 구조로 레벨 추가와 수정이 쉬움
- 맵 에디터, 온라인 맵 공유, 추가 기믹 확장 가능
- 발표 및 시연에 적합한 완성형 소형 게임 프로젝트

---

## 슬라이드 10. 마무리

- 핵심 키워드: 원버튼 조작 / 중력 회전 / 데이터 기반 레벨
- 목표: 단순하지만 완성도 높은 퍼즐 액션 구현
