# Gravity Rotate 발표문

## 발표 시작

안녕하세요. 제가 제작한 게임 **Gravity Rotate**를 소개하겠습니다.

이 게임은 **클릭 또는 터치 한 번으로 중력을 회전시키는 원버튼 퍼즐 액션 게임**입니다.
플레이어는 직접 이동하는 것이 아니라, 현재 중력 방향으로 계속 움직입니다.
그래서 사용자는 이동 버튼 대신, **언제 중력을 바꿀지 판단하는 것**에 집중하게 됩니다.

제가 이 작품을 기획한 이유는 조작은 최대한 단순하게 만들면서도,
퍼즐의 깊이와 액션의 긴장감을 동시에 보여주고 싶었기 때문입니다.
한 번의 입력이 바로 경로 전체를 바꾸기 때문에,
짧은 맵에서도 생각할 요소가 많아지는 점이 이 게임의 핵심입니다.

---

## 게임 소개 및 기획 의도

Gravity Rotate의 핵심 목표는
**누구나 바로 이해할 수 있는 조작**과
**익숙해질수록 더 전략적으로 보이는 구조**를 만드는 것이었습니다.

게임 안에서 플레이어는 네모 블록 형태로 표현되고,
벽, 가시, 포탈, 목표 타일 같은 오브젝트를 이용해 맵을 공략합니다.
처음에는 단순히 중력을 바꾸는 방법만 익히지만,
후반으로 갈수록 포탈과 장애물이 섞이면서 경로를 미리 계산해야 합니다.

즉, 초반에는 직관적으로 즐길 수 있고,
후반에는 사고력이 필요한 구조로 난이도가 확장되도록 설계했습니다.

---

## 기술 스택

기술 스택은 비교적 단순하게 구성했습니다.

개발 언어는 **Python 3**이고,
게임 프레임워크는 **Pygame 2**를 사용했습니다.
외부 의존성을 많이 늘리지 않고,
핵심 시스템을 직접 구현하는 방향으로 진행했습니다.

또한 맵 데이터는 **JSON 파일**로 분리해서 관리했습니다.
이렇게 하면 게임 코드와 레벨 데이터를 분리할 수 있어서,
맵 수정이나 추가가 훨씬 쉬워집니다.

저장 데이터는 `save.json`으로 관리해서
레벨 해금 상태와 설정값이 유지되도록 만들었습니다.

---

## 구현 설명 1: 전체 구조

프로젝트 구조는 크게 `core`, `scenes`, `gameplay`, `map` 폴더로 나누었습니다.

`core`에서는 게임 실행, 설정, 저장, 씬 전환 같은 공통 기능을 담당합니다.
`scenes`에서는 메인 메뉴, 레벨 선택, 설정, 게임 화면, 결과 화면을 관리합니다.
`gameplay`에서는 실제 플레이에 필요한
플레이어 이동, 타일맵 처리, 포탈 로직, 파티클 효과를 담당합니다.
그리고 `map` 폴더에는 각 레벨이 JSON 파일 단위로 저장됩니다.

이렇게 분리한 이유는
기능별 책임을 명확하게 나눠서 수정과 확장을 쉽게 하기 위해서입니다.

---

## 구현 설명 2: 핵심 플레이 로직

가장 중요한 부분은 **중력 회전과 물리 처리**입니다.

플레이어는 매 프레임 현재 중력 방향으로 가속하고,
입력이 들어오면 중력 방향이 90도 반시계 방향으로 회전합니다.
이때 속도 벡터도 같이 회전시켜서,
방향만 바뀌는 것이 아니라 관성이 유지되도록 구현했습니다.

그래서 단순히 방향 전환만 되는 것이 아니라,
플레이어가 기존의 속도를 가진 채 새로운 방향으로 흐르게 됩니다.
이 점이 게임의 손맛과 퍼즐성을 동시에 만들어 줍니다.

---

## 구현 설명 3: 충돌, 포탈, 맵 시스템

충돌 처리는 타일 기반으로 구현했습니다.
플레이어는 사각형 충돌 박스를 사용하고,
이동할 때 X축과 Y축을 나누어 충돌을 해결해서
벽에 끼이거나 튕기는 현상을 줄였습니다.

포탈은 같은 ID를 가진 타일끼리 연결되도록 만들었고,
텔레포트 직후에는 짧은 쿨다운을 줘서
포탈 안에서 무한 반복 이동하는 문제를 막았습니다.

맵은 JSON으로 읽어 오기 때문에,
코드를 크게 수정하지 않아도 레벨 파일만 추가하면 자동으로 레벨 목록에 반영됩니다.
이 구조는 발표 이후 확장이나 유지보수에도 유리합니다.

---

## 구현 설명 4: 완성도 요소

단순히 플레이만 가능한 수준에서 끝나지 않도록,
완성도 요소도 함께 넣었습니다.

예를 들어 메인 메뉴, 레벨 선택, 설정 화면, 결과 화면을 따로 만들었고,
일시정지 메뉴에서는 재시작이나 레벨 스킵도 가능하게 했습니다.

또한 HUD, 배경, 타일 표현, 포탈 효과, 파티클 연출을 추가해서
작지만 완성된 게임처럼 보이도록 신경 썼습니다.

최근에는 타일을 단순한 색 사각형이 아니라
조금 더 입체적인 패널 형태로 다시 그려서
전체 화면이 더 또렷하고 분위기 있게 보이도록 개선했습니다.

---

## 마무리

정리하면, Gravity Rotate는
**원버튼 조작**, **중력 회전 중심 퍼즐 구조**,
그리고 **JSON 기반 확장 가능한 맵 시스템**을 핵심으로 하는 게임입니다.

단순한 조작만으로도 충분한 전략성과 재미를 만들 수 있다는 점을 보여주고 싶었고,
메뉴, 설정, 저장, 포탈 같은 시스템까지 포함해서
하나의 완성된 작품 형태로 구현하는 것을 목표로 했습니다.

이상으로 발표를 마치겠습니다. 감사합니다.
