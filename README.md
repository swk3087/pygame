# Gravity Rotate (Pygame)

좌/우 입력으로 중력을 90도 회전시키며 목표 타일에 도달하는 타일 기반 퍼즐 액션 게임입니다.

## 실행 방법

1. Python 3.10+ 환경 준비
2. 의존성 설치
   - `pip install -r requirements.txt`
3. 실행
   - `python main.py`

## 조작

- 좌클릭: 중력 반시계 회전 (CCW 90도)
- 우클릭: 중력 시계 회전 (CW 90도)
- 터치: 화면 왼쪽 터치(반시계), 오른쪽 터치(시계)
- `ESC`: 일시정지 또는 뒤로
- `R`: 현재 레벨 재시작
- `0`: 플레이 화면 텍스트(HUD) 표시/숨김

## 주요 기능

- 메인 메뉴 / 레벨 선택 / 설정 / 결과 화면
- JSON 타일맵 자동 로드 (`map/*.json`, 파일명 사전순)
- 포탈 그룹 텔레포트 + 재진입 쿨다운
- 스파이크 리스폰
- 저장 데이터 (`save.json`)
  - 레벨 해금
  - 최고 기록(클릭 수 / 시간)
  - 설정(볼륨, 전체화면, 화면 배율, 화면 흔들림)

## 맵 포맷

맵 파일은 `agent.md`의 JSON 스펙을 따릅니다.

- 필수 키: `meta`, `tile_size`, `width`, `height`, `legend`, `grid`
- 포탈: `PORTAL:n`
- 튜토리얼: `tutorial` 배열

맵 검증 실패 시 게임이 크래시하지 않고 로드 실패 메시지를 표시합니다.
