# Gravity Rotate (Pygame)

클릭/터치 한 가지 입력만으로 중력을 90도 반시계 방향으로 회전시키며 목표 타일에 도달하는 타일 기반 퍼즐 액션 게임입니다.

## 실행 방법

1. Python 3.10+ 환경 준비
2. 의존성 설치
   - `pip install -r requirements.txt`
3. 실행
   - `python main.py`

## 조작

- 좌클릭 / 터치: 중력 회전 (CCW 90도)
- `ESC`: 일시정지 또는 뒤로
- `R`: 현재 레벨 재시작

## 주요 기능

- 메인 메뉴 / 레벨 선택 / 설정 / 결과 화면
- JSON 타일맵 자동 로드 (`map/*.json`, 파일명 사전순)
- 포탈 그룹 텔레포트 + 재진입 쿨다운
- 스파이크 리스폰
- 저장 데이터 (`save.json`)
  - 레벨 해금
  - 최고 기록(클릭 수 / 시간)
  - 설정(볼륨, 전체화면, 화면 배율, 화면 흔들림)

## 맵 포맷

맵 파일은 `agent.md`의 JSON 스펙을 따릅니다.

- 필수 키: `meta`, `tile_size`, `width`, `height`, `legend`, `grid`
- 포탈: `PORTAL:n`
- 튜토리얼: `tutorial` 배열

맵 검증 실패 시 게임이 크래시하지 않고 로드 실패 메시지를 표시합니다.
